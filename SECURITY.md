# Security policy

Please do not post an exploitable vulnerability, credential, or real genealogy data in a public issue. Use GitHub's **Report a vulnerability** private advisory flow for this repository if it is enabled. If private reporting is unavailable, contact the maintainer privately through the repository owner's profile before sharing details.

Include the affected version or commit, a minimal reproduction using synthetic data, impact, and any suggested fix. This prototype has no published support or response-time guarantee. Do not test against another person's data or infrastructure.
